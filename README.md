# Guide — Vibe Coding (ia-aplicada)

Material de apoio dos vídeos do canal **ia-aplicada** sobre vibe coding: programar com IA com compreensão real do que está acontecendo, não aprovação por confiança.

Cada vídeo vira uma pasta em `episodes/` com o kit completo: conceito, roteiro, mapa visual, glossário, títulos/thumbnail/SEO e cortes para Shorts.

## Episódios

|---|---|---|
| 01 | Deploy do Zero ao Ar | [`episodes/01-deploy-do-zero-ao-ar/`](./episodes/01-deploy-do-zero-ao-ar/) |

## Estrutura de cada episódio

- `README.md` — índice e visão geral
- `00-conceito-do-video.md` — tese, público, estrutura
- `01-roteiro-completo.md` — roteiro falado com timestamps
- `02-mapa-de-camadas.md` — diagrama visual
- `03-glossario-minimo.md` — termos que aparecem, 1 linha cada
- `04-titulos-thumbnail-seo.md` — títulos, thumbnail, tags
- `05-shorts-cortes.md` — cortes curtos para Shorts/Reels

## Princípios

- Narrativa linear, didática, sem jargão desnecessário
- Cada termo técnico é traduzido em 1 frase antes de continuar
- Conceito só entra se responde "o que quebra se isso faltar"
- Saída replicável: glossário cresce a cada vídeo
