# YouTube ia-aplicada - Banco de Dados (video simples, arquitetural)

**Eixo:** narrativa unica linear. A historia de onde os dados sobrevivem quando ninguem esta olhando. Cada conceito (memoria volatil, tipos de banco, query, schema, migracao, riscos) aparece no momento em que a jornada precisa dele.

**Nao e:** comparativo exaustivo de bancos, curso de SQL, aprofundamento de um sistema especifico. E o mapa mental do por que o banco existe, o que ele guarda, e o que quebra quando se ignora ele.

**Publico:** quem esta começando com desenvolvimento / vibe coders / pessoas que usam IA para programar mas nao entendem onde os dados ficam entre um request e outro.

**Duracao alvo:** 15-20 min.

| Arquivo | O que e |
|---|---|
| `00-conceito-do-video.md` | Tese, publico, 3 atos, tom |
| `01-roteiro-completo.md` | Roteiro falado linear com timestamps (o coracao) |
| `02-mapa-de-camadas.md` | Visual de camadas para mostrar na tela / base do thumbnail |
| `03-glossario-minimo.md` | So os termos que aparecem no roteiro, 1 linha cada |
| `04-titulos-thumbnail-seo.md` | Titulos, thumbnail, tags |
| `05-shorts-cortes.md` | 4 cortes curtos, cada um isola uma camada |

**Principios do canal aplicados**
- Didatica por analogia operacional: o banco vira analogia do mundo fisico (carrinho de compras, memoria do navegador)
- Conceito so entra se responde "o que quebra se isso faltar"
- Termina com repo publico + glossario que cresce por video (saida replicavel)
- Alerta pratico para vibe coders: a IA as vezes ignora schema e migracao, e isso quebra silenciosamente
