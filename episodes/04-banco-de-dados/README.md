# YouTube ia-aplicada - Banco de Dados (vídeo simples, arquitetural)

**Eixo:** narrativa única linear. A história de onde os dados sobrevivem quando o processo do servidor reinicia, roda em várias cópias, ou atende outro dispositivo. Cada conceito (memória não confiável, tipos de banco, query, schema, migração, riscos) aparece no momento em que a jornada precisa dele.

**Não é:** comparativo exaustivo de bancos, curso de SQL, aprofundamento de um sistema específico. É o mapa mental do por que o banco existe, o que ele guarda, e o que quebra quando se ignora ele.

**Público:** quem está começando com desenvolvimento / vibe coders / pessoas que usam IA para programar mas não entendem onde os dados ficam entre um request e outro.

**Duração alvo:** 15-20 min.

| Arquivo | O que é |
|---|---|
| `00-conceito-do-video.md` | Tese, público, 3 atos, tom |
| `01-roteiro-completo.md` | Roteiro falado linear com timestamps (o coração) |
| `02-mapa-de-camadas.md` | Visual de camadas para mostrar na tela / base do thumbnail |
| `03-glossario-minimo.md` | Só os termos que aparecem no roteiro, 1 linha cada |
| `04-titulos-thumbnail-seo.md` | Títulos, thumbnail, tags |
| `05-shorts-cortes.md` | 4 cortes curtos, cada um isola uma camada |

**Princípios do canal aplicados**
- Didática por analogia operacional: o banco vira analogia do mundo físico (conta criada, pedido confirmado, perfil aberto em outro dispositivo)
- Conceito só entra se responde "o que quebra se isso faltar"
- Termina com repo público + glossário que cresce por vídeo (saída replicável)
- Alerta prático para vibe coders: a IA às vezes ignora schema e migração; quando algo dá errado, o banco costuma avisar, mas a aplicação pode ignorar o aviso
