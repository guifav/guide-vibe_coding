# Shorts e cortes

Cada corte isola um conceito do diálogo request/response, com gancho para o vídeo completo.

## Short 1 - Request e Response: a conversa invisível

**Gancho (0-3s):** "Você clica e a tela muda. Mas o que viajou entre o clique e a resposta?"

**Corpo:** quase tudo na web é uma conversa de duas partes. O navegador manda um pedido (request). O servidor processa e devolve uma resposta (response). Isso acontece toda vez que você abre um site, clica num botão, carrega uma lista. No fundo, é request e response.

**CTA:** "No vídeo completo eu abro essa conversa inteira, até o JSON. Link na descrição."

## Short 2 - GET vs POST: pedir vs enviar

**Gancho:** "GET e POST. Só isso já cobre 90% da web."

**Corpo:** GET é pedir. Abrir página, carregar lista, ver produto. O navegador diz "me dá isso". POST é enviar. Preencher formulário, criar conta, adicionar ao carrinho. O navegador diz "aqui estão dados, faz algo". A diferença é simples: GET pede, POST envia.

**CTA:** "Quer entender o diálogo inteiro? Vídeo completo no canal."

## Short 3 - Status codes: 200, 404, 500 (a IA precisa ser honesta)

**Gancho:** "404 não significa 'quebrou'. Significa 'não achei'. São coisas diferentes."

**Corpo:** o servidor devolve um código de status que diz, honestamente, o que aconteceu. 200 é sucesso. 404 é "não achei". 401 é "não te conheço". 403 é "não pode". 500 é "quebrou no meu lado". O pior é o crash silencioso, quando o servidor quebra e devolve nada.

**CTA:** "Os 5 status codes que cobrem 95% dos casos, explicados no vídeo completo."

## Short 4 - Contrato: quando a IA inventa a API

**Gancho:** "A IA escreveu o front pra consumir uma API. Mas ela inventou os campos."

**Corpo:** contrato é o combinado entre front e servidor: o que eu peço vs o que recebo. Se o servidor devolve `nome` e o front espera `título`, quebra. A IA às vezes chuta os campos sem verificar o contrato real. Tela fica vazia e ninguém sabe por quê. Pergunta certa: "você viu o contrato ou chutou?".

**CTA:** "As 3 armadilhas da IA com API, no vídeo completo do canal."
